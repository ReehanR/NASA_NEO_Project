# 🚀 NASA Asteroid Dashboard

A professional NASA Near-Earth Object (NEO) Tracking Dashboard built using Python, Streamlit, SQLite, Pandas, and Matplotlib.

## Features
- Asteroid Analytics Dashboard
- Hazardous Asteroid Detection
- Fastest Asteroids Tracking
- Closest Asteroids To Earth
- Search Asteroid Feature
- Interactive Charts and Graphs
- Date-wise Filtering

## Technologies Used
- Python
- Streamlit
- SQLite
- Pandas
- Matplotlib
- NASA API

## Run Project

streamlit run app.py
